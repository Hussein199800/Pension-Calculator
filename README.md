# حاسبة المحامي

قسمان منفصلان في موقع واحد: **الراتب التقاعدي** و**الانتساب والرسوم**، ولكل قسم حاسبته وتقريره وحالاته المحفوظة. التنقل من قائمة جانبية (تُفتح بزر ☰ على الهاتف)، وصفحة **«الشرح»** توضح طريقة الحساب في القسمين بأمثلة.

## قسم الانتساب والرسوم

- **انتساب جديد**: العمر بتاريخ الانتساب (أي كسر يرفعه لسنة، دون 30 = سطر 30، فوق 50 = سطر 50 مع تنبيه)، وجدول سنة الانتساب أو الجدول الذي بعدها، وكل بنود سطر العمر ما عدا الرسم السنوي، ثم الرسم السنوي لكل سنة من سنة الانتساب حتى سنة النهاية (قيده سارٍ / مرقّن / متوفى / وضع آخر)، مع خانة «مدفوع» لكل سنة.
- **إعادة القيد والنقل**: مشطوب أمني، مشطوب إداري، ترقين بطلب المحامي، إعادة قيد بعد الترقين، مُغفَل، نقل من فرع لآخر، نقل متمرن إلى الأساتذة. (المعفى من التمرين: قيد الدراسة.)
- الجداول في `js/fees.js` (بالعملة الجديدة، مطابقة لملف fees_2026.xlsx ويتحقق منها `tests/fees.test.js`).

## قسم الراتب التقاعدي

صفحة ويب (تعمل بدون خادم وبدون إنترنت) لحساب:

- **التقاعد العادي**: معاش كامل (30 سنة) / جزئي (أقل من 30) / كامل مع علاوة (أكثر من 30، بسقف 45 سنة).
- **التقاعد الصحي**: شرائح الربع / النصف / ثلاثة الأرباع / الكامل، أو كامل المعاش إذا كانت الحالة ناتجة عن المهنة، ويُصرف من تاريخ الخبرة الطبية.
- **معاش الورثة**: لورثة المتقاعد أو المتوفى على رأس عمله، مع تحديد أهلية كل وارث تلقائياً وتوزيع الحصص.
- **معونة التقاعد** و**معونة الوفاة**: حسب تاريخ الانتساب (قبل/بعد 4/2/2014) وجدول قيم المعونة عبر السنوات.

ويُنشئ **تقريراً مفصلاً** بلغة بسيطة لإضافته إلى إضبارة المحامي: بيانات المحامي، خلاصة النتيجة مع التفقيط، طريقة حساب مدة الممارسة والمدد المستبعدة، القاعدة والمعادلة بالأرقام، جدول المستحقات شهراً بشهر، توزيع حصص الورثة، المعونة، الأساس القانوني، شرح المصطلحات، وخانات التوقيع.

## الاستخدام

افتح `index.html` في أي متصفح (أو عبر GitHub Pages).

- **تسجيل الدخول**: محلي على كل جهاز. الحساب الافتراضي `admin` / `1234` — غيّره من «بيانات الدخول» أسفل القائمة الجانبية.
- **التصميم**: هوية «الزيتون والعاج»، بوضع نهاري وليلي، وقائمة جانبية بثلاث مجموعات: الراتب التقاعدي، الانتساب والرسوم، عام.
- **قريباً (واجهة فقط حالياً)**: رفع النسخ الاحتياطية إلى تيليجرام، والمزامنة والدخول بحساب Google عبر Firebase.

- **حفظ الحالة**: تُحفظ في المتصفح نفسه، وتظهر في تبويب «الحالات» مع البحث بالاسم أو رقم الإضبارة.
- **النسخ الاحتياطي**: تحميل ملف بكل الحالات (التقاعد والرسوم) والإعدادات، واستيراده على أي جهاز (يضيف ولا يحذف).
- **طباعة التقرير / حفظ PDF**: من زر الطباعة (اختر "حفظ كـ PDF").
- **تنزيل التقرير**: ملف HTML مستقل يُفتح لاحقاً ويُطبع.
- **الإعدادات والقيم**: جدول قيمة الراتب الكامل وجدول قيمة المعونة عبر الزمن، وقواعد معالجة كسور السنة. عند صدور زيادة جديدة أضف سطراً بتاريخ نفاذها، وكل شهر يُحسب بالقيمة النافذة فيه.

## القواعد المعتمدة (من التعاميم المرفقة)

| البند | القيمة الافتراضية |
|---|---|
| الراتب الكامل | 4,000 قبل 1/7/2026، و16,000 بعد زيادة 300% |
| سقف سنوات المعاش | 45 سنة (= 24,000، أي 2,400,000 ل.س قديمة) |
| معونة التقاعد والوفاة | 20,000 (≤2020) ← 24,000 ← 28,000 ← 35,000 ← 50,000 ← 100,000 (9/2024) ← 200,000 |
| التقريب | إهمال الكسور (لأسفل) في كل خطوة كما في الأمثلة |
| الشهر الأول الجزئي | المبلغ × الأيام المتبقية من الشهر ÷ 30 |
| معاش الورثة | 3 حصص للزوجات، حصة لكل ولد، حصة للوالدين، حصة للأخوات + حصة لخزانة التقاعد |
